GitHub repository
Live demo of a student project. You play the contact, a lead talking to the sales assistant of the business. Every assistant reply is generated live by a language model (Qwen 2.5 7B Instruct). Scheduling requests are validated and saved by application code. Times you mention are interpreted in the contact's timezone (-; it is now - there). Nothing here dials a real phone or touches a real calendar - those are simulated providers.
